1.20-0.0.10-beta:
- Reopening a block repositions that player's existing panel while preserving its pin state; other players' panels stay separate.
- Added uniform bordered window controls with hover tooltips, optional manual help and session-only pinning for block panels. Mounted panels have no close or pin controls.
- Looking directly away from an unpinned panel now correctly allows its automatic timeout to expire.
- Installed item toggles now use brightness without a white outline.
- Numeric sliders can show percentage units, and panels can hide controls that do not apply to the current selection.
- Added in-world integer sliders with dragging and precise arrow controls, plus a consistent looping-arrow style for cycle choices.
- Added multiline text entry with standard editing and clipboard controls, plus a holographic color picker with buttons showing the selected color.
- Ported HoloGui to Minecraft 1.20.1 for Forge.
- Fixed a problem with 'opaque' mode not working
- Various cleanups and fixes
- Fixed a problem on servers
